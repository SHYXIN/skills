# 中文简报（cn-brief-wx）

把 agent 刚才那一连串英文的步骤、工具调用和输出，翻译成你能跟上的中文汇报。它不强迫模型说中文，只在你需要时把已经发生的事讲成人话。

## 三条铁律
- **只汇报、不代劳**：它不做任何新操作、不继续任务、不改方向，除非你明说"继续 / 去做 X"。
- **锚定真实信息**：引用真实的文件名、命令、工具名、关键输出片段；英文专有名词（`self_check.py`、`role="img"`、`git diff`）原样保留，只翻译周围叙述。
- **中文为主**：叙述、推理、结论全程中文；代码、命令、路径、标识符保留原文。

## 工作流
按顺序执行；每步以完成标准收尾。

### 1. 划定范围
确定复盘哪一段：默认"最近一轮任务 / 最近若干步"，或你指定的某时间点之后。
- 完成标准：范围已明确（"最近 N 步"或某标记之后），未跑题。

### 2. 回看会话
从会话历史抽这一段里 agent 实际做的事：调了哪些工具（Read / Bash / Write / Edit…）、对每个工具干了什么、得到什么观察或结果、agent 自己的叙述与推理。
- 完成标准：已列出该段关键动作与结果，且每条都锚定到真实工具 / 文件 / 输出，无编造。

### 3. 用中文复述
按下面结构输出（紧凑，别照抄英文原文，用中文讲清）：
- **目标**：这一段在解决什么。
- **做了什么**（按时间 / 步骤）：每步一句中文——"调了 X，去 Y，得到 Z"；英文命令 / 路径原样保留。
- **关键发现 / 决策**：过程中得出的重要结论或拐弯。
- **现在到哪了**：当前状态、是否卡住、还留什么。
- 完成标准：四部分齐全，且每步都对应真实动作而非虚构。

### 4. 收尾
问你是否要深挖某一步、或继续任务。不擅自行动。
- 完成标准：把球交还给你，未擅自动手。

## 输出格式
分节 + 每步一行。英文专有名词（文件名、命令、参数、标识符）保留原样，只翻译叙述。这是给你看的人话简报，不是给 agent 的执行计划。
