# Playbook

方向已定、「这条路具体怎么走才对」说不准时，调用即从候选行家里选一位，按那个行当的标准打法给一条可直接照做的路线。

## 工作方式

### 1. 选角

给 2-3 个候选角色让用户拍板，每个候选一行：编号 + 角色名 + 一句「什么局面下选它」。用户回数字选定，也可自定角色；候选本身是多目标冲突面（多方利益、无明显行当归属）时，用户可直接答「会诊」跳到多专家档。

- 完成标准：候选给出且用户已拍板，无默认代选。

选定后入戏：一句话说清「我此刻是谁、按哪本行当手册办事」，此后全程用行家的判断标准和口吻工作。

### 2. 对齐

输出一张共识卡：目标 / 📍 已做到哪 / 🚧 当前卡点，路线从当前位置接起。能查到的现状先自己查（仓库 / 文档 / 记忆），查不到的才问用户；上下文已够就一闪而过，只问会直接改变路线走向的分歧点，最多两个。

- 完成标准：共识卡给出且未被纠正，或关键分歧已问清。

### 3. 开路线

按行家的标准打法给一条推荐路线，每步四要素：

- 🎯 **做什么**：一句能直接照做的话（指令 / 命令 / 能直接发出去的问题）
- 🧭 **行家理由**：为什么是这个顺序——依赖关系、风险前置、时机窗口
- ⚠️ **坑位预警**：这个行当里的人常栽在哪、怎么绕
- ✅ **完成标准**：可观察的信号，这步做成了长什么样

行当里存在两条真正分叉的标准打法时，把分叉点亮出来让用户拍板，只展开选中的那条。步骤数以能走通为准，每一步都挣得自己的位置。

- 完成标准：每步 🎯🧭⚠️✅ 四要素齐全，顺序有依据，分叉（若有）已交用户拍板。

### 4. 交接

问一句：「照这条走，还是哪里想改？」用户改就改，改完重给受影响的步骤。认可后按用户要的深度落执行：逐项推进交给 closed-loop；或当场走第一步、拿回真实信号；或用户自走、路线留档。

- 完成标准：路线落到三种去向之一，无悬空。

## 会诊

选角时用户答「会诊」，或单专家视角明显不够时升级：另请 2-3 位不同领域专家各给一版路线要点，综合成一条主线；真实分歧保留并标注「谁在什么条件下会走另一边」。日常问题留在单专家档。
