# agent-eval-first — agent 行为的评测先行

agent 的「代码」是 md/skill 文案，行为由 LLM 现场生成，断言写不死。本 skill 用**对话剧本**承载行为预期：每条案例 = 一轮用户输入 + AI 的完整预期回复 + 判分标注（必现关键词/禁词/长度）。剧本是唯一源，编译衍生出两样东西——评测案例 JSON（机器跑）与对话 HTML（人评审）。

## 核心循环

```
grill 收尾（需求最鲜活）
   │
   ▼
① 写对话剧本（MD）─────► 编译 ──► 案例 JSON + 对话 HTML
   │                                    │
   │                                    └─ HTML 给人评审，不满意回 ① 改剧本
   ▼
② 跑红（默认可跳，见下）──► ③ 改 md/skill ──► ④ 跑绿（默认可跳）
   │
存量改动（改措辞/修规则/发版前）：
   ① 跑基线 → ② 改 → ③ 再跑 → ④ diff 无退步   （护栏轨，两轮真跑）
```

选轨判据：**这个行为是「还没有」还是「已有但不能坏」**。还没有→先行轨；已有→护栏轨。大改动两轨都走。

## 步骤

### 1. 把行为预期写成对话剧本

新行为的剧本就是它的可执行 spec——写不出剧本 = 行为还没想清楚，先回 grilling。**时机在 grill 收尾时**：此时需求最鲜活，顺手落成剧本；不要等动手改 md 前才补。

剧本与被测 md/skill **同仓存放**（放其 `eval/` 目录），不进 skill 仓。语法与写法纪律以 `references/script-format.md` 为唯一源，照它写。

### 2. 编译 + 评审

剧本写完即编译：`scripts/compile.py` 从剧本生成案例 JSON 与对话 HTML（衍生品永不手改，改剧本重编译）。

对话 HTML 是静态分镜预览（用户消息在右、预期回复在左、判分点高亮），给不读 JSON 的人评审「预期对话长什么样」。评审不通过回步骤 1 改剧本。

### 3. 跑红 / 跑基线

**跑红默认可跳**：默认只写剧本、编译交付，不真跑红，直接进步骤 4 改 md/skill。想真跑红时用户点名即可（「红检跑一下」「先跑红再改」）；agent 主动建议跑红仅限一种情况：改动会**翻转既有裁决**（改路由分支、删门禁、换产物契约），且用户没有给出真实失败证据时。

- 先行轨（跑了的话）：改 md **之前**跑一轮，新案例必须红（当前 agent 做不到 = 案例有效；直接绿 = 案例写错了或行为已存在，回步骤 1 修剧本）
- 护栏轨：改之前跑一轮当基线，label 用 `baseline-<日期>`（两轮真跑是 diff 的结构必需，不属于「可跳」范围）

### 4. 改 md/skill

同一文案多处同步维护的，在同一 commit 内改齐再进入下一步，别带着半同步状态跑绿。

### 5. 跑绿 / 再跑 + diff

跑绿**默认同样可跳**；与跑红独立决定——跳了红检不等于必须跳绿检，反之亦然。

agent 主动建议跑绿（护栏轨或先行轨）仅限一种情况：改动会**翻转既有裁决**且用户没给真实验证证据时。

- 先行轨（跑了的话）：新案例全绿才算改完。**跳过红检后直接绿要按可疑处理**——案例从未被证明「能红」，先查案例有效性（是不是写松了、行为是不是本来就有），再庆祝改好
- 护栏轨：跑第二轮后 diff 两轮，**逐 case 看**「新增红」和「消失绿」

### 6. flaky 仲裁（唯一允许的复跑）

agent 会抖动：diff 里出现的「新增红/消失绿」**不直接定罪**，用执行器的单 case 复跑能力仲裁一次——复跑绿 = 抖动，记录不管；复跑仍红 = 真退步，回步骤 4。红期（步骤 3 先行轨）的案例不适用仲裁：跑红是预期行为，没有定罪问题。

### 7. 红期排查（改不动时）

绿不了别急着反复改 md——先用会话取证看 agent **实际收到了什么注入、实际调了什么工具**，区分「规则没写对」和「规则没被读到」。先建反馈回路，再动手。

## 收尾

- 剧本 + 编译产物留在被测仓 `eval/`，作为下一次改动的基线资产（护栏轨的输入就是它）
- 跳过红检/绿检时，交付说明里写明「剧本路径 + 未执行」，用户想验证时随时可跑
- 两轮 run 的 diff 报告路径写进交付说明（MR 描述/会话结论），证据可回溯

## 执行器

跑案例的命令、参数、路径等可变事实见 `references/executors.md`。换评测通道时只改该文件，本文件不动。
