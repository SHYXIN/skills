用户迷路了，需要一张地图。画出当前任务/对话的全景，让用户重新定位。

## 触发

用户主动喊出触发词（如 "where am i"、"给我张地图"、"我在哪"）时才画。不要自动画，不要主动画。

## 输出格式

纯文字缩进层级，不使用 mermaid 或其他依赖渲染的格式。一次只画一张图。

```text
📍 任务/目标：一句话概括当前在做什么

├─ ✅ 已定
│  ├─ <决策点>：<结论>（<为什么>）
│  └─ ...
├─ 📍 你在这：<当前正在处理的决策点>
│  ├─ ⬜ 待定：<还没回答的问题>
│  ├─ ~~<被否决的选项>~~：<一句否决原因>
│  └─ 懂这个需要：<名词>——<一句话大白话解释>（想深挖可用 eli5-zh / learn-by-minimal）
├─ ⬜ 未决
│  └─ <还没走到的问题>（<一句话说明它管什么>）
└─ ~~<早期被否决的分支>~~：<一句否决原因>
```

## 规则

1. **当前位置唯一**：全图只有一处 📍，用户一眼定位。
2. **否决项弱化保留**：被否决的选项不删除，用 ~~删除线~~ 或缩进到底层压低视觉权重，附一句否决原因——"为什么没走这条路"是整体理解的一半。
3. **知识前置轻量**：每个节点旁最多标注 2-3 个关键前置知识，名词 + 一句话解释。地图只负责"让你看见自己缺什么"，深讲交给 eli5-zh / learn-by-minimal。
4. **通用适用**：不限于 grill-one 问答。读代码、做调研、聊方案中迷路都可用——地图内容相应调整为"目标 / 已定决策 / 当前位置 / 未决问题 / 背景知识"。
5. **画完即停**：输出地图后不再追问、不展开无关分支。用户看清位置后自己决定继续什么。
