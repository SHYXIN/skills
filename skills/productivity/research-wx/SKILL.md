# 研究（research-wx）

起一个**后台 agent** 去做调研，你这边继续干活，它边读边整理。

它的任务：

1. **只信一手来源**：官方文档、源码、规范、第一方 API——不要拿二手转述当结论。每条结论都追回到"拥有它的那个来源"。
2. **把发现写成一个 Markdown 文件**，每条 claim 都注明出处。
3. **存到仓库本来放这类笔记的地方**：沿用既有约定；若没有约定，挑个合理位置（如 `docs/research/` 或仓库根 `notes/`）并告诉用户放哪了。

## 工作流
按顺序执行；每步以完成标准收尾。

### 1. 派发后台 agent
把问题、范围、以及你手上已有的线索，交给一个后台 agent（别在前台干等它读完）。
- 完成标准：后台任务已发起，且已把"调研什么 / 要一手来源 / 要带出处"交代清楚。

### 2. 收口与落盘
后台 agent 回来后，确认产物满足：单一 Markdown、每条结论有可点击的出处、位置符合仓库约定或被明确说明。
- 完成标准：Markdown 已落盘，且三要素（一手来源 / 带出处 / 位置合理）齐全。

## 自检（输出前过一遍）
- [ ] 结论追到一手来源、没用二手转述顶替？
- [ ] 每条 claim 都标了出处？
- [ ] 文件落到了仓库合理位置、并已告知用户？
