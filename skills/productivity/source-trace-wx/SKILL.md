---

起一个**后台 agent** 去追出处，这样你读结果时还能继续干活。它的任务：

1. **先挖真实出处**：回看本次对话，把所有 agent 实际用过的来源（WebFetch / WebSearch 的真实网址、读过的文件或文档路径）按 claim 对应列出。每条能在对话记录里追到的，直接标“对话里用过”。
2. **再补盲区**：对没有任何可追溯来源的 claim，像 research-wx 一样去查**一手来源**——官方文档、源码、规范、第一方 API——而不是它们的二手转述，并把权威链接补上。
3. 把结果写成一个 Markdown 文件，每条 claim 注明出处，并区分「高信任一手来源」与「二手来源」：
   - 高信任一手来源：官方文档 / 源码 / 规范 / 第一方 API。
   - 二手来源：博客、论坛、聚合页——只作线索，须追到其引用的一手来源才算坐实。
4. 存到仓库放这类笔记的地方；沿用既有约定，若没有约定，就写到 `sources/` 目录（文件名按被追溯的回答主题命名）并说明放哪了。

对话里同时给一段简短摘要：一共几条 claim、几条有真实出处、几条是补查得到、各来源链接。
