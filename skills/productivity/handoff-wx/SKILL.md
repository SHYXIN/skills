# 交接文档（handoff-wx）

把当前对话压缩成一份交接文档，让一个全新的 agent 会话能无缝接手。场景不限——代码开发、调研、写作、协作都适用。

## 存储位置

按顺序探测，取第一个命中的目录（目录不存在则先创建）：

1. 当前工作目录下有 `temp/` → 存 `<cwd>/temp/handoffs/`
2. 当前工作目录下有 `tmp/` → 存 `<cwd>/tmp/handoffs/`
3. 都没有 → 退回 OS 临时目录的 `handoffs/` 子目录（Windows 为 `%TEMP%` 下 `handoffs`，类 Unix 为 `$TMPDIR` 下 `handoffs`，无 `$TMPDIR` 则 `/tmp/handoffs`）

文件名：`YYYY-MM-DD_HHMM_主题.md`（如 `2026-10-17_1530_示例主题.md`），主题取自本次对话核心任务。

不存进任何项目工作区（上述 `temp/`、`tmp/` 中转目录除外）。

## 文档内容

- **任务现状**：目标是什么、走到哪了、下一步是什么。下一步要具体到可执行。
- **已定决策**：关键结论 + 一句为什么。被否决的选项也记一句否决原因，防止下个会话重新踩一遍。
- **未决问题**：还悬着什么、各自的候选方向。
- **建议技能（suggested skills）**：下个 agent 应调用哪些技能（点名具体技能名），优先从本库技能里指。
- **现场指针**：相关文件路径、URL、命令。只给指针，不复制正文。

## 纪律

- **不复制已有工件的内容**（计划、规格、ADR、issue、提交、笔记、文档等），一律用路径或 URL 引用。
- **脱敏**：API key、密码、个人信息等一律略去或打码。
- 用户传了参数时，把参数当作"下个会话要做什么"的说明，交接文档据此裁剪侧重点。
