# ELI5 中文版 — 像给五岁小孩一样解释（Explain Like I Am 5）

> 一个 CodeBuddy / Claude Code 技能，能把任何东西讲给任何人听——小孩、经理、工程师、爸妈。它会根据听众自动调整语气、词汇、类比和切入角度。

需要给经理讲清楚一个技术概念？或者把代码掰开揉碎讲给五年级小孩？ELI5 中文版让 AI 根据你说的听众，自动切换讲解风格。

> 本技能改编自 [DreambigOu/ELI5](https://github.com/DreambigOu/ELI5)，内容全部中文化并做了适度本地化（类比换成中文读者更熟悉的日常场景）。

## 支持的受众

| 类别 | 例子 |
|------|------|
| **年龄** | 5岁、10岁、15岁、20-30岁、40岁以上 |
| **学龄 / 学历** | 五年级、初中、高中、大学生、研究生 |
| **职业角色** | 经理、工程师、设计师、总监、同事、产品经理 |
| **关系** | 妻子/丈夫、父母、孩子、朋友 |

## 用法示例

```
用五岁小孩能懂的话讲讲什么是数据库索引
给我经理解释这段代码
给五年级学生讲讲 git 合并冲突怎么来的
给我妈解释这个报错
给设计师简化一下
ELI5 什么是缓存
```

## 工作原理

技能从你的提示里识别目标受众，并据此校准：

- **词汇** —— 对小孩零术语，对工程师用正确术语
- **类比** —— 对 5 岁用玩具和 playground，对经理用业务结果
- **语气** —— 对孩子活泼，对总监专业，对家人温暖
- **深度** —— 简单受众短平快，研究生受众讲细微差别
- **切入角度** —— 对经理讲影响/风险，对设计师讲体验，对工程师讲架构

## 安装

把技能放进你的 CodeBuddy / Claude Code 技能目录：

```bash
# 复制整个 eli5-zh 文件夹到技能目录，例如：
cp -r eli5-zh ~/.codebuddy/skills/eli5-zh
# 或 Claude Code：
cp -r eli5-zh ~/.claude/skills/eli5-zh
```

然后在对话里说「ELI5 这个」「给我经理解释一下」之类的就能触发。
