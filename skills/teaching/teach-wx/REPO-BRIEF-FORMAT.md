# REPO-BRIEF.md 格式

`REPO-BRIEF.md` 放在教学工作区根目录。它用于保存 GitHub 仓库或代码库的快速技术导览，帮助后续学习先有地图。

只有用户想保留导览，或后续会围绕该仓库多轮学习时才生成。

## 模板

````md
# Repo Brief: {仓库名}

## 一句话定位
{这个项目是什么，解决什么问题。}

## 适合先知道的背景
- {必要背景一}
- {必要背景二}

## 目录地图
```text
{关键目录树，只保留学习需要的部分}
```

## 主流程
```text
{请求流 / 数据流 / 构建流 / CLI 执行流等}
```

## 核心概念
- `{概念}`：{它为什么存在，解决什么问题}

## 重点文件
- `{path}`：{为什么值得看}

## 推荐学习路线
1. {第一个可完成学习单元}
2. {第二个可完成学习单元}
3. {第三个可完成学习单元}

## 暂不展开
- {当前阶段不重要或容易分散注意力的部分}
````

## 规则

- 先读 README、配置文件、入口文件、核心模块和示例/测试，再写判断。
- 不把整个目录树贴满，只保留能帮助理解主流程的部分。
- 不写成项目宣传文案。
- 如果事实不确定，明确标注“待确认”，不要猜。
