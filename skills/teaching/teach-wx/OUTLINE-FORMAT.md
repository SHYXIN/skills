# OUTLINE.md 格式

`OUTLINE.md` 放在教学工作区根目录。它记录当前学习主线、当前位置和旁路问题，防止澄清问题把教学路线带偏。

## 模板

```md
# Outline: {主题}

## 主线目标
{这条学习路线最终要解决什么问题。保持具体，不写成课程广告。}

## 当前节奏
{fast / normal / slow。说明为什么使用这个节奏。}

## 当前大纲
1. {20-40 分钟内能完成的学习单元}
2. {下一个学习单元}
3. {下一个学习单元}

## 当前位置
- 当前节点：{正在学哪一项}
- 当前问题：{正在澄清或推进的问题}
- 下一步：{回答后应该回到哪里}

## 旁路问题
- {问题}：已回答 / 待回答 / 候选并入主线

## 大纲调整记录
- {日期或序号}：{为什么调整，调整了什么}
```

## 规则

- 大纲节点必须是可完成学习单元，不是宽泛章节名。
- 用户澄清问题默认不改变大纲。
- 用户明确要求“加入大纲 / 单独开一节 / 调整路线 / 重新规划”时，才修改大纲。
- 每次推进主线后，更新 `当前位置`。
- 节奏变化明显时，更新 `当前节奏`。
- 保持短小。`OUTLINE.md` 是导航，不是完整教材。
