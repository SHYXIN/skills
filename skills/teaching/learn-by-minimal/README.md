# 从最小实例学起（learn-by-minimal）

> 一个 CodeBuddy / Claude Code 学习教练技能。用「最小实例 → 逐部件扩展 → 全景可视化」的方法，带用户学会**任何可拆解的知识或系统**——不限于代码框架。

框架越做越大、越精细，但核心部件往往就那么几个。这个技能先给你一个**最小可运行/可体验的实例**，再带你把每个部件逐个点亮，最后拼出完整结构并可视化成一张图。适合用来搞懂：React、Vue、TCP、快速排序、下单链路、一套协议、一个业务流程……

## 学习方式

1. **定位与背景**：开始前先给一张**定位卡**——它是什么 / 给谁用 / 什么场景 / 为什么出现 / 有什么好处 / 同类工具。写进讲义开头，一句确认后开始。默认必做，可一句话跳过；想较真同类工具时，可搭配 `research-wx` 派后台调研一份带出处的资料。
2. **最小实例**：写一个尽可能小的 demo（代码类能跑、非代码类能体验），只覆盖核心路径。
3. **学习地图**：用 Mermaid 画一张组件图，初始只有核心 3-5 个节点，按依赖排序。
4. **逐部件点亮**：一次聚焦一个部件——讲解 + 扩展一点 demo + 在地图高亮当前节点 + 出一道选择题/判断题校验理解。
5. **地图长大**：学到哪、地图长到哪，新依赖的部件作为新节点长出来。
6. **全景可视化**：全部点亮后，`MAP.md` 就是完整结构图——即最终可视化成果。

## 用法示例

```
教我 React
用最小 demo 学一下 TCP 三次握手
从零带我学快速排序
一步步学下单链路
learn-by-minimal 依赖注入
```

## 校验设计

每步默认用**选择题 / 判断题**（不要求"用自己的话讲"）。题目有深度：干扰项反映常见误解，不是一眼能看穿的表层题；判断题的陈述带微妙错误，需真理解才能选对。答错则换角度重讲。

## 进度存储

每主题独立 workspace，位于用户主目录，更新技能不丢进度：

```
~/.learn-by-minimal/<主题>/demo      # 最小实例
~/.learn-by-minimal/<主题>/MAP.md    # Mermaid 学习地图（含进度）
~/.learn-by-minimal/<主题>/notes.md  # 讲义（开头是定位卡引言，其后各节点讲解全文）
```

再次学习同一主题会自动恢复进度，从第一个未学会的节点继续。
