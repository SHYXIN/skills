# 配色（单一真源）

**生成任何图前先读这里。** 所有颜色选择以本文件为准——形状填充、描边、文字色、背景区域。

## 浅色模式

### 形状填充（柔和背景色）

| 颜色 | Hex | 用途 |
|------|-----|------|
| 浅蓝 | `#a5d8ff` | 输入、来源、主链路 |
| 浅绿 | `#b2f2bb` | 成功、输出 |
| 浅橙 | `#ffd8a8` | 警告、待处理 |
| 浅紫 | `#d0bfff` | 处理、中间件 |
| 浅红 | `#ffc9c9` | 错误、关键 |
| 浅黄 | `#fff3bf` | 注释、决策 |
| 浅青 | `#c3fae8` | 存储、数据 |
| 浅粉 | `#eebefa` | 分析、指标 |

### 背景区域（用 `opacity: 30`）

| 颜色 | Hex | 用途 |
|------|-----|------|
| 蓝区 | `#dbe4ff` | 前端层 |
| 紫区 | `#e5dbff` | 逻辑/agent 层 |
| 绿区 | `#d3f9d8` | 数据/工具层 |

### 描边 / 文字主色

`#4a9eed` 蓝 · `#f59e0b` 琥珀 · `#22c55e` 绿 · `#ef4444` 红 · `#8b5cf6` 紫 · `#ec4899` 粉 · `#06b6d4` 青 · `#84cc16` 柠檬绿

- 文字在浅底上：主 `#1e1e1e`，最浅不低于 `#757575`。

## 深色模式

先用深色背景板（见 [methodology.md](./methodology.md)），再用下列配色：

### 深色填充

| 颜色 | Hex | 用途 |
|------|-----|------|
| 深蓝 | `#1e3a5f` | 输入、来源、前端 |
| 深绿 | `#1a4d2e` | 成功、输出、数据 |
| 深紫 | `#2d1b69` | 处理、逻辑/agent |
| 深橙 | `#5c3d1a` | 警告、任务队列 |
| 深红 | `#5c1a1a` | 错误、关键 |
| 深青 | `#1a4d4d` | 存储、缓存 |

### 深色文字

- 主文字 `#e5e5e5`、次要 `#a0a0a0`——在元素上用 `strokeColor` 指定。

### 深色背景板

```json
{ "type": "rectangle", "id": "darkbg", "x": -4000, "y": -3000, "width": 10000, "height": 7500, "backgroundColor": "#1e1e2e", "fillStyle": "solid", "strokeColor": "transparent", "strokeWidth": 0 }
```

## 用法约定

- 用 `backgroundColor` 时**总是同时设** `fillStyle: "solid"`。
- 描边色与填充色搭配：浅色模式下通常「深一点的同色系」做描边（如填充 `#a5d8ff` + 描边 `#4a9eed`）。
- 深色模式下形状描边用对应的亮色主色（如填充 `#1e3a5f` + 描边 `#4a9eed`）。
- 要换品牌色，只改本文件——其余文件不硬编码颜色。
