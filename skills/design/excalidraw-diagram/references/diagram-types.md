# 图型选型（9 类）

按需求的"动词"选图型，不要按名词。选好后用 [methodology.md](./methodology.md) 排布局、[color-palette.md](./color-palette.md) 定色。

| # | 图型 | 用户在问什么 | 典型信号 |
|---|------|-------------|---------|
| 1 | 流程图 | "怎么做""走一遍步骤" | 步骤、顺序、条件分支 |
| 2 | 关系图 | "谁和谁有关""怎么连的" | 实体、依赖、关联 |
| 3 | 思维导图 | "围绕它有哪些点" | 发散主题、分类展开 |
| 4 | 架构图 | "由什么组成""怎么部署" | 服务、模块、组件、拓扑 |
| 5 | 数据流图 | "数据从哪来到哪去" | 输入、处理、存储、输出 |
| 6 | 泳道图 | "谁负责哪一步" | 多方协作、职责边界、业务流 |
| 7 | 类图 | "有哪些类、什么关系" | 面向对象、继承、聚合 |
| 8 | 时序图 | "谁先调用谁" | 消息传递、API 调用链 |
| 9 | ER 图 | "表之间什么关系" | 实体、字段、一对多、多对多 |

---

## 1. 流程图

**骨架**：开始(`rectangle`) → [判断(`diamond`)] → 处理(`rectangle`) → 结束。分支箭头从 diamond 的左右/下引出，标签写"是/否"。

- 主链用横向或纵向单一方向，别来回折。
- 分支终点形状区分：成功用绿、失败用红。

## 2. 关系图

**骨架**：中心节点放中间，相关实体围一圈，箭头带关系标签。

- 关系标签动词化（"调用""依赖""拥有"），不要只画线。
- 节点按角色配色（见调色板）。

## 3. 思维导图

**骨架**：中心主题 → 一级分支（放射状）→ 二级节点。

- 用椭圆做中心，一级分支用不同色。
- 层级越深字号越小（中心 28 → 一级 20 → 二级 16）。

## 4. 架构图

**骨架**：用背景区域（`opacity: 30` 的大矩形）分层——前端层 / 逻辑层 / 数据层，每层里放组件方框，跨层用箭头。

- 层标题用小号 text 放区域左上角。
- 组件方框 `label` 写组件名，箭头写协议（"REST""SQL"）。
- 这是最常用的图型，示例见 [../SKILL.md](../SKILL.md) 与 CLI 的 kitchen-sink 示例。

## 5. 数据流图

**骨架**：外部实体 → 处理过程 → 数据存储 → 输出。用箭头串起来，箭头上标数据形态。

- 存储用圆柱感（`ellipse` 或配色区分），处理用 `rectangle`。

## 6. 泳道图

**骨架**：先画几条横向/纵向的大背景区长条（每条约 200px 高），每条左上角标角色名；再把步骤按角色放进对应泳道，跨泳道用箭头。

- 角色数 ≥2 时用它，比普通流程图更能表达"谁负责"。

## 7. 类图

**骨架**：每个类一个 `rectangle`，`label` 里用 `\n` 分行写「类名\n——\n字段\n——\n方法」。

- 继承用 `endArrowhead: "triangle"`（空心三角感），关联用普通箭头，聚合/组合在标签里注明。

## 8. 时序图

**骨架**：顶部一排参与者方框；每个参与者向下画一条生命线（细长 `rectangle`）；消息用水平箭头，从上到下按时间排列，箭头 `label` 写方法名。

- 时间自上而下，别混入左右向的"步骤"。

## 9. ER 图

**骨架**：每个实体一个 `rectangle`，`label` 分两段「实体名\n——\n主键/字段」。关系用箭头 + 标签（1:1 / 1:N / N:M）。

- 主键可加粗或单独配色，外键在标签里标注。

## 通用骨架模板

**带标签的方框（复制即用）**

```json
{ "type": "rectangle", "id": "ID", "x": X, "y": Y, "width": 200, "height": 80, "backgroundColor": "#a5d8ff", "fillStyle": "solid", "label": { "text": "标签" } }
```

**深色版**

```json
{ "type": "rectangle", "id": "ID", "x": X, "y": Y, "width": 200, "height": 80, "backgroundColor": "#1e3a5f", "fillStyle": "solid", "strokeColor": "#4a9eed", "label": { "text": "标签", "strokeColor": "#e5e5e5" } }
```

**箭头（复制即用）**

```json
{ "type": "arrow", "id": "AID", "x": X, "y": Y, "width": W, "height": 0, "points": [[0,0],[W,0]], "endArrowhead": "arrow", "startBinding": { "elementId": "FROM", "fixedPoint": [1, 0.5] }, "endBinding": { "elementId": "TO", "fixedPoint": [0, 0.5] } }
```

**深色背景板（放数组第一个）**

```json
{ "type": "rectangle", "id": "darkbg", "x": -4000, "y": -3000, "width": 10000, "height": 7500, "backgroundColor": "#1e1e2e", "fillStyle": "solid", "strokeColor": "transparent", "strokeWidth": 0 }
```
